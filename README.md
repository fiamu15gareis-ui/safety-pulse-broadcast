# Safety Pulse Broadcast

Estoy tratando de prototipar una app para Android que sirva para transmitir información a los servicios de emergencia en el contexto de una catástrofe natural. La app debería constar de dos partes: Una, donde el usuario pueda cargar su información personal y de su grupo familiar; y otra para que, en caso de una emergencia, el celular envíe esta información a un dispositivo electrónico que a su vez lo transmita como ondas de radio en una frecuencia definida. En caos de no contar con conectividad wifi o señal, la app sólo debería transmitir como dato las coordenadas del celular al momento de presionar el botón de emergencia.
